# Python and Bioinformatics Foundations

Early Python coursework from my bioinformatics studies, covering basic programming and introductory sequence-alignment exercises.

## Contents

- [Algorithm](Algorithm) and [Algorithm2](Algorithm2): sequence-alignment experiments using scoring matrices and traceback.
- [homework-0](homework-0/): introductory Python assignment.
- [homework-1](homework-1/): further Python practice.

The alignment files contain Python code even though their names have no .py extension. This is a historical learning archive; examples should be reviewed individually before running.

For more extensive work, see [Algorithmic Bioinformatics](https://github.com/enterlina/algorithm_bioinf), [Machine Learning](https://github.com/enterlina/ML), and [NGS Analysis](https://github.com/enterlina/NGS).
